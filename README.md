# Early laboratory screening for coded endocarditis

The most recent analysis behind the manuscript evaluates whether routine laboratory measurements available early in an admission can distinguish hospitalizations with coded endocarditis. Models were developed in MIMIC-III and evaluated in eICU-CRD.

**[Start with the v18 manuscript analysis](analysis/v18/README.md)** for the findings and study notebook. [Try the synthetic demo](analysis/v18/README.md#run-the-synthetic-demo) without clinical data, or follow the [reproduction guide](analysis/v18/reproducibility/README.md) for the full analysis.
